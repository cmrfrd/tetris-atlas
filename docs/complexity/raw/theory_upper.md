## statements

SETUP (fixed for all statements). A game instance over dimensions (n,m), n,m ≥ 1, consists of: a board b ⊆ [n]×[m] given as an explicit nm-bit bitmap; a bag state B, a nonempty subset of the 7 piece types (the multiset of pieces remaining in the current bag — a set, since a bag is a permutation of the 7 distinct types); and a current piece p. A placement action for piece p is a pair a=(r,c) with r a rotation state of p (≤4 per piece) and c a column such that the rotated shape's footprint [c, c+width) fits in [0,n). Per piece there are ≤ 4n actions (162 total (piece,rotation,column) triples at n=10 under the engine's rotation-state convention; the constant is irrelevant, only Θ(n) matters). The transition step(b,p,r,c) is: hard-drop by skyline (landing base z = max over footprint columns j of h_j − ℓ_j, where h_j is the column height of b and ℓ_j the piece's lowest relative cell in column j; no cavity entry possible), merge, clear all full rows (rows above shift down), then loss iff resulting max column height > m. Non-lost states always fit in the n×m grid, and simulation of one step uses an n×(m+4) scratch grid, since the landing base is ≤ m for a non-lost predecessor. Convention: if a piece has no legal placement (possible only for n=1), the state is losing. Bag dynamics: after the player places p, the adversary/randomizer draws the next piece q from B (if B=∅ it is first refilled to all 7 types); the new bag state is B∖{q} (or full-minus-q after refill).

THEOREM A (for (a)) — COMPLETE. P1 (OFFLINE-HD: given (n,m,b,w), does some placement sequence place all of w without ever losing?) is in NP, with certificate = the placement sequence itself: |w| pairs (r_i,c_i), each of 2+⌈log₂ n⌉ bits, total O(|w|·log n) = O(|input|²) bits, verified by deterministic simulation in O(|w|·nm) time. The "clear the board" variant (additionally require the final board empty) is also in NP with the same certificate. P1' (OFFLINE-HD-BAG: P1 restricted to bag-legal w) is in NP: bag-legality of w is decidable in linear time, and the restriction of an NP language to a P-decidable set of inputs is in NP.

THEOREM B (for (b)) — COMPLETE. P2 (ONLINE-HORIZON: given (n,m,b,B,p,N) with N in unary, can the player guarantee placing N pieces against an adaptive bag adversary?) is in PSPACE. A minimax depth-first search of the alternating game tree (player branching ≤ 4n, adversary branching ≤ |B| ≤ 7, depth N rounds) decides it in space O(N·(nm + log n)) = O(|input|²), which is polynomial because N ≤ |input| in unary. Correctness is Zermelo backward induction on the finite tree.

THEOREM C (for (c)) — COMPLETE. P3 (ATLAS-MEMBERSHIP: same input without N; can the player guarantee surviving forever?) is in EXPTIME. Precisely: build the finite two-player safety arena with player positions (b,B,p), adversary positions (b,B), and a sink ⊥; |V| ≤ 2^{nm}·2^7·7 + 2^{nm}·2^7 + 1 = 2^{O(nm)} and |E| ≤ |V|·(4n+7). The player's winning region W equals the greatest fixed point W = νX.(Safe ∩ CPre(X)), where CPre(X) = {player nodes with some successor in X} ∪ {adversary nodes with all successors in X}. W is computable as the complement of the adversary's attractor to ⊥ in time O(|V|+|E|)·poly(n,m) = 2^{O(nm)}, which is 2^{poly(|input|)} since the board bitmap makes |input| ≥ nm. s ∈ W iff the player can survive forever from s (Lemma C1: positional determinacy of finite reachability/safety games, proved from scratch via the attractor-rank induction; Lemma C2: W = gfp, proved by showing W is a fixed point and every post-fixed point avoids every attractor level). Moreover both players have memoryless deterministic winning strategies on their regions, and from the adversary's region A = V∖W the adversary forces ⊥ within K ≤ |V| rounds against ALL player behaviors (including randomized, history-dependent).

THEOREM D (for (d)) — COMPLETE. For every state s: the player can guarantee adversarial survival from s (s ∈ W) ⟺ the player has a strategy surviving with probability 1 when pieces are drawn uniformly at random from the remaining bag (⟺ surviving surely, i.e., on every sample path). Quantitatively: if s ∈ W, the positional deterministic strategy σ from Theorem C survives on every play (so a.s. survival needs neither randomization nor memory); if s ∈ A, then for EVERY player strategy π (randomized, history-dependent), P_{s,π}(death) ≥ 7^{−K} > 0 with K ≤ |V| the attractor depth — hence no strategy survives a.s. CAVEAT, stated as part of the theorem's honest form: from s ∈ A we do NOT claim almost-sure death; the random draws can exit A into W (adversary nodes in A need only ONE successor in A), after which a good player survives. The equivalence needs only "positive death probability from A", which is what is proved; the folklore "death forced i.o. with prob ≥ δ ⇒ a.s. death" argument is valid only for the event (death ∨ eventual absorption in W), and that weaker dichotomy is also proved (Lemma D3, via Lévy/Borel–Cantelli-type iteration).

STATEMENT E (for (e)) — honest assessment, no theorem claimed. P3 ∈ PSPACE is OPEN in both directions here. (i) What would suffice: a proof that every yes-instance admits a poly(nm)-size circuit C defining a set S_C with s₀ ∈ S_C, S_C ⊆ Safe, and one-step closure (∀s∈S_C ∃placement ∀draw: successor ∈ S_C) — soundness of such certificates is automatic and checking a given C is in Π₂^p ⊆ PSPACE, so guessing C gives Σ₃^p ⊆ PSPACE; dually a succinct ranked adversary strategy would certify non-membership. No such succinctness bound is known (and this project's empirical evidence — carriers > 10^6 states with no small closed sets found — points against easy succinctness). (ii) Why the naive gfp does not give PSPACE: it manipulates subsets of a 2^{O(nm)} arena (exponential space), and the horizon-capped reformulation "survive forever ⟺ survive |V| rounds" turns the Theorem-B DFS into exponential depth, hence exponential stack. The natural algorithm is an alternating poly-space computation, and APSPACE = EXPTIME (Chandra–Kozen–Stockmeyer, JACM 1981) — this route provably tops out at EXPTIME. (iii) Lower bounds: succinctly presented safety/reachability games are EXPTIME-complete in general (Stockmeyer–Chandra-style game hardness), so there is no generic collapse to PSPACE; but no EXPTIME-hardness reduction into THIS specific ruleset is given or claimed. P3 could be EXPTIME-complete (then P3 ∉ PSPACE unless PSPACE=EXPTIME) or could be in PSPACE; nothing here settles it.

THEOREM F (for (f)) — COMPLETE (given Theorem C). P4 (EMPTY-DIMS: input (n,m) only; empty board, fresh bag, adversary draws the first piece; survive forever) is decidable, immediately from Theorem C: P4(n,m) = ∧_{q∈7 types} P3(n,m, empty, Full∖{q}, q). Complexity relative to encoding: with n,m in BINARY, input length ℓ = Θ(log n + log m) and the Theorem-C algorithm runs in 2^{O(nm)} = 2^{2^{O(ℓ)}} time, placing P4 ∈ 2-EXPTIME; with n,m in UNARY (ℓ = n+m), 2^{O(nm)} = 2^{O(ℓ²)}, placing P4 ∈ EXPTIME. For each FIXED (n,m) (e.g., canonical 10×20), P4 is a single bit, trivially O(1); the classification is only meaningful for the uniform family. No matching lower bounds claimed.

## proofs

Throughout, one simulation step step(b,p,r,c) is computed as in SETUP; each of (landing base, merge, clear, height recomputation, loss test) is O(nm) bit operations. This is the ruleset as stated: pure skyline hard-drop (no cavity entry), clear-then-loss-check.

================ (a) THEOREM A — COMPLETE ================
P1 ∈ NP. Certificate: the sequence π = ((r_1,c_1),…,(r_k,c_k)), k = |w|. Encoding: r_i in 2 bits, c_i in ⌈log₂ n⌉ bits; since the board is an explicit nm-bit bitmap and w is explicit, |input| ≥ nm + k, and n ≤ 2^{|input|} always gives log n ≤ |input|; in fact n is recoverable from the bitmap so log n ≤ log |input| + O(1) and the certificate is O(k log n) = O(|input| log |input|) bits — polynomial either way.
Verifier V(input, π): (1) check |π| = |w|; (2) set b_0 := b; for i = 1..k: check r_i is a legal rotation state of piece w_i and c_i ∈ {0,…,n − width(w_i,r_i)} (reject otherwise); compute b_i := step(b_{i−1}, w_i, r_i, c_i) on the n×(m+4) scratch grid; reject if the loss predicate fires (max height > m after clears); (3) accept. Running time O(k·nm) — polynomial.
Completeness: if some placement sequence survives, that sequence (its (rotation,column) pairs) is accepted by V, because V performs exactly the game dynamics. Soundness: if V accepts π, then by construction every intermediate state is non-lost and all k pieces are placed, i.e., π survives. Both directions are immediate because the game is deterministic given the placements: V's simulation IS the unique induced play. Hence P1 ∈ NP.
Board-clear variant: same certificate; V additionally checks b_k = ∅ in O(nm). Same argument. ∈ NP.
P1' ∈ NP. Bag-legality of w relative to a given starting bag B₀ (default: fresh bag, B₀ = all 7): the legal sequences are exactly those where the first |B₀'|-block is a sequence of distinct types drawn from B₀, and thereafter consecutive blocks of length 7 each consist of 7 distinct types (i.e., a permutation of the full set), with the final block allowed to be a proper prefix (distinct types). Decidable by a single linear scan maintaining the current remaining-set (7-bit): for each w_i check w_i ∈ remaining, remove it, refill when empty; reject on violation. O(|w|) time. Two equivalent ways to conclude: (i) define P1' so that bag-illegal inputs are "no"-instances; the NP verifier first runs the scan and rejects if illegal, then runs the P1 verifier — still poly-time, so P1' ∈ NP; (ii) as a promise restriction: any NP language intersected with a P-decidable input set is in NP by the same verifier composition. Either way P1' ∈ NP. ∎

================ (b) THEOREM B — COMPLETE ================
Game formalization. Positions: player positions (b,B,p,k) meaning "k pieces still to place, current piece p, bag remainder B"; the player chooses a legal action a=(r,c) for p; if step(b,p,r,c) is lost, that branch is losing (but the player may try other actions); if non-lost and k=1, the player has survived; if non-lost and k>1, the adversary chooses q from B (refilled if empty) and play continues at (b', B∖{q} [after refill if applied], q, k−1). If p has no legal action (only possible for n=1), the position is losing. The player "guarantees surviving N pieces" iff the player wins this finite perfect-information game from (b,B,p,N).
Algorithm SURVIVE(b,B,p,k):
  if k = 0: return true.  // vacuous horizon
  for each rotation r of p, for each column c ∈ {0,…,n−width(p,r)}:
     b' := step(b,p,r,c)
     if b' not lost:
        if k = 1: return true
        B_d := (B = ∅ ? FullBag : B)   // set to draw from
        ok := true
        for each q ∈ B_d: if ¬SURVIVE(b', B_d∖{q}, q, k−1): ok := false; break
        if ok: return true
  return false.
Correctness (induction on k): For k=0 trivially true = "survive 0 pieces". For k ≥ 1: the player wins iff ∃ legal action a such that the resulting b' is non-lost and (k=1, done) or ∀ adversary draws q ∈ B_d the player wins the (k−1)-subgame — this is exactly Zermelo backward induction on a finite tree (depth ≤ 2N, finite branching), where the minimax value exists and equals the ∃∀-recursion; SURVIVE computes precisely that recursion. (Finite perfect-information games are determined and their values are computed by backward induction; no citation needed beyond induction.)
Space accounting: recursion depth ≤ N (one frame per piece placed; the adversary loop lives inside the frame). Each frame stores: b' (n(m+4) ≤ nm+4n bits; non-lost states fit in n×m, the scratch is transient), B and B_d and the q-iterator (≤ 3·7 bits), p (3 bits), r (2 bits), c (⌈log n⌉ bits), k (⌈log N⌉ bits), plus O(nm) work space for step (reusable, one per frame in the worst case for clean accounting). Total space O(N·(nm + log n + log N)) bits. Since N is in UNARY, N ≤ |input|, and nm ≤ |input| (the board bitmap is part of the input), so space = O(|input|²) — polynomial. Time is bounded by (4n·7)^N (irrelevant to the claim). Branching as claimed: player ≤ 4n, adversary ≤ 7. Hence P2 ∈ PSPACE.
(Equivalently: the ∃∀-recursion is an alternating Turing machine running in time O(N·poly(nm)) = poly, and ATIME(poly) = PSPACE by Chandra–Kozen–Stockmeyer, "Alternation", JACM 28(1), 1981; the explicit DFS above makes the space bound self-contained.)
Remark (not part of the theorem): if N were given in binary, survive-min(N, K) with K = attractor depth from Theorem C makes P2 decidable in EXPTIME; and for N ≥ |V| it coincides with P3. ∎

================ (c) THEOREM C — COMPLETE ================
Arena G = (V, E): V = V_P ∪ V_A ∪ {⊥}. V_P = {(b,B,p) : b a non-lost n×m board, B ⊆ 7 types (∅ allowed, ≡ pre-refill), p a type}. V_A = {(b,B)}. ⊥ = sink (lost), with a self-loop. Edges: from (b,B,p) ∈ V_P, for each legal action a of p: to ⊥ if step is lost, else to (b',B) ∈ V_A; if p has no legal action, a single edge to ⊥. From (b,B) ∈ V_A with draw set B_d = (B=∅ ? Full : B): for each q ∈ B_d, an edge to (b', … ,q) with new bag B_d∖{q}. Player moves at V_P, adversary at V_A; ⊥ is absorbing. Counting: |V_P| ≤ 2^{nm}·2^7·7, |V_A| ≤ 2^{nm}·2^7, so |V| ≤ 2^{nm}·2^7·7 + 2^{nm}·2^7 + 1 = 2^{O(nm)}; out-degree ≤ max(4n,7), so |E| ≤ |V|(4n+7). A play is an infinite path; the PLAYER's objective is the safety condition "never visit ⊥"; the ADVERSARY's is the reachability condition "visit ⊥". "Survive forever from s" ⟺ the player has a strategy (a priori arbitrary: history-dependent) such that every consistent play from s avoids ⊥. Every position has ≥ 1 outgoing edge, so plays are total.
LEMMA C1 (attractor / positional determinacy) — COMPLETE. Define A_0 = {⊥}; A_{i+1} = A_i ∪ {v ∈ V_A : ∃(v,u)∈E, u∈A_i} ∪ {v ∈ V_P : ∀(v,u)∈E, u∈A_i}. The sequence is ⊆-increasing over a finite V, hence stabilizes at some A := A_K with K ≤ |V|. Let W := V∖A. Define rank(v) = min{i : v ∈ A_i} on A. Claims:
 (C1a) Every v ∈ V_P ∩ W has some successor in W; every v ∈ V_A ∩ W has ALL successors in W. Proof: if all successors of a player node were in A = A_K, the node would be in A_{K+1} = A_K, contradiction; if some successor of an adversary node were in A, the node would be in A. ∎
 (C1b) Player's positional deterministic strategy σ: at each v ∈ V_P ∩ W pick (arbitrarily, fixed) a successor in W (exists by C1a); elsewhere arbitrary. Then every play from any s ∈ W in which the player follows σ remains in W forever: by induction on play steps, using C1a at adversary nodes (all successors stay in W) and the definition of σ at player nodes. Since ⊥ ∈ A, no such play visits ⊥. So σ is a winning (surviving) strategy from every s ∈ W. ∎
 (C1c) Adversary's positional deterministic strategy τ: at each v ∈ V_A ∩ A with rank(v) = i+1 pick a successor of rank ≤ i (exists by definition of A_{i+1}); elsewhere arbitrary. Then from any s ∈ A, EVERY play in which the adversary follows τ reaches ⊥ within rank(s) ≤ K steps, REGARDLESS of the player's behavior (arbitrary history-dependent, randomized realized however): by induction on rank — at an adversary node of rank i+1, τ moves to rank ≤ i; at a player node of rank i+1, by definition of A_{i+1} ALL successors have rank ≤ i, so whatever the player plays the rank strictly decreases; rank 0 is ⊥. ∎
 (C1b)+(C1c) give determinacy with memoryless deterministic strategies on both sides: V = W ⊎ A, player wins exactly from W, adversary from A.
LEMMA C2 (gfp characterization) — COMPLETE. Define F: 2^V → 2^V by F(X) = Safe ∩ CPre(X), Safe = V∖{⊥}, CPre(X) = {v∈V_P : ∃ successor ∈ X} ∪ {v∈V_A : ∀ successors ∈ X}. F is monotone, so by Knaster–Tarski νF (the greatest fixed point = greatest post-fixed point, i.e., greatest Z with Z ⊆ F(Z)) exists. Claim W = νF.
 (⊆) W is a post-fixed point: W ⊆ Safe (⊥ ∈ A_0 ⊆ A) and W ⊆ CPre(W) by C1a. Hence W ⊆ νF.
 (⊇) Let Z ⊆ F(Z) be any post-fixed point. Show by induction on i that Z ∩ A_i = ∅. i=0: Z ⊆ Safe excludes ⊥. Step: suppose Z ∩ A_i = ∅ and take v ∈ Z ∩ (A_{i+1}∖A_i) for contradiction. If v ∈ V_P: v ∈ CPre(Z) gives a successor u ∈ Z; but A_{i+1}-membership of a player node forces ALL successors into A_i, so u ∈ Z ∩ A_i = ∅ — contradiction. If v ∈ V_A: v ∈ CPre(Z) gives ALL successors in Z; but A_{i+1}-membership gives SOME successor in A_i, again contradicting Z ∩ A_i = ∅. So Z ∩ A = ∅, i.e., Z ⊆ W. Hence νF ⊆ W. ∎
 Consequently W is exactly the standard νX.(Safe ∩ CPre(X)) — the "gfp safe set" the Atlas answers.
LEMMA C3 (semantics) — COMPLETE. Player can survive forever from s ⟺ s ∈ W. (⇐) is C1b (σ survives against everything). (⇒) contrapositive: if s ∈ A, then by C1c the adversary's τ defeats every player strategy in ≤ K steps, so no player strategy survives. ∎  (This is exactly why the converged gfp characterizes "survive forever": positional determinacy of finite safety/reachability games; textbook reference for the general facts used: E. Grädel, W. Thomas, T. Wilke (eds.), "Automata, Logics, and Infinite Games", LNCS 2500, 2002, Ch. 2 (attractors, positional determinacy of reachability/safety games); determinacy alternatively from D. A. Martin, "Borel determinacy", Ann. Math. 102 (1975), of which safety/reachability is the trivial closed/open case — the self-contained proof above avoids any reliance.)
Complexity — COMPLETE. Enumerate V (each state is nm + 7 + 3 bits ⇒ enumeration 2^{nm+10}·poly); successors of a state are computed in poly(n,m) each, ≤ 4n+7 of them. Compute A by the standard counter algorithm (for each player node keep a counter of successors not yet in A; a player node enters A when its counter hits 0, i.e., all successors in A — note player nodes need ALL successors in A, adversary nodes need ONE): each edge is processed O(1) times, total O(|V| + |E|)·poly(nm) = 2^{O(nm)}·poly(n,m) = 2^{O(nm)}. (The naive |V| rounds of applying F, each O(|E|), gives 2^{O(nm)} as well; either suffices.) Since the input contains the board bitmap, |input| ≥ nm, so the running time is 2^{O(|input|)} ⊆ 2^{poly(|input|)}: P3 ∈ EXPTIME. Answer: output [s₀ ∈ W]. ∎
(Alternative one-line proof for the record: the game is decided by an alternating Turing machine using O(nm) space — current state + a counter to |V|, since by C1c "survive forever" ⟺ "survive |V| rounds" — and ASPACE(poly) = EXPTIME [Chandra–Kozen–Stockmeyer 1981]. The explicit construction above is primary.)

================ (d) THEOREM D — COMPLETE ================
Probability model. Fix a start state s₀ ∈ V∖{⊥} and a player strategy π: a map from histories ending in a V_P-position to probability distributions over that position's legal actions (this subsumes deterministic and memoryless strategies). Nature replaces the adversary: at each V_A-position with draw set B_d, the next piece is uniform on B_d, independent of everything else given the history. The tree of histories is finitely branching; Ionescu–Tulcea (or the Kolmogorov extension on a countable product) yields a unique probability measure P_{s₀,π} on infinite plays. "Death" = the event that the play visits ⊥; "survival" = its complement. Full-support property used: at every V_A node, every available draw has probability 1/|B_d| ≥ 1/7.
Direction 1 (s₀ ∈ W ⇒ a.s. survival, indeed sure survival) — COMPLETE. Take the positional deterministic σ of C1b and let π = σ. By C1b, EVERY play from s₀ consistent with σ stays in W and never visits ⊥ — in particular every sample path survives, so P_{s₀,σ}(survival) = 1. This also disposes of the "randomized/history-dependent" worry on the membership side: memoryless deterministic suffices, because positional determinacy (C1b/C1c) was proved for the safety game outright; randomization cannot help the player since sure survival is already achieved, and no strategy of any kind achieves more than probability 1.
Direction 2 (s₀ ∈ A ⇒ every π has P_{s₀,π}(death) ≥ 7^{−K} > 0) — COMPLETE. Let τ and rank be as in C1c; K = max rank ≤ |V|. Claim: for every history h ending in a state s ∈ A with rank(s) = i, P_{s₀,π}(death within the next i steps | h) ≥ 7^{−i}. Induction on i. i=0: s = ⊥, probability 1. Step, s of rank i+1: If s ∈ V_P: conditioned on h, the player draws an action from π(h); by C1c's player-node property, EVERY successor has rank ≤ i; condition on the realized action and apply the induction hypothesis to the extended history: each conditional probability is ≥ 7^{−i}, hence so is the mixture, and 7^{−i} ≥ 7^{−(i+1)}. If s ∈ V_A: with probability 1/|B_d| ≥ 1/7 the realized draw is exactly the τ(s)-successor, which has rank ≤ i; conditioning on that draw and applying the induction hypothesis, P(death within i+1 | h) ≥ (1/7)·7^{−i} = 7^{−(i+1)}. (Measurability is trivial: all events are unions of finite-history cylinders; the conditioning is on cylinders of positive probability.) Applying the claim at the empty history: P_{s₀,π}(death) ≥ 7^{−rank(s₀)} ≥ 7^{−K} > 0. Hence no strategy survives with probability 1 from A. ∎
Combining: {∃π : P(survival)=1} ⟺ s₀ ∈ W ⟺ adversarial survivability (C3). This is the claimed equivalence, and it holds verbatim for the Atlas's state space with s₀ = (b, bag_state, current_piece). The only property of the randomizer used is full support on the bag-legal draws, so any bag randomization with min-probability δ>0 gives the same theorem with 7^{−K} replaced by δ^K.
LEMMA D3 (the correct form of the "infinitely often" argument) — COMPLETE. From any s₀ and any π: P_{s₀,π}(the play visits A infinitely often AND survives) = 0; equivalently, almost surely either the play dies or it eventually stays in W forever. Proof: let E_t = {play is in A at time t}. On E_t, Direction 2's claim gives P(death within K steps | F_t) ≥ 7^{−K} =: δ on that event (F_t = history σ-algebra). Define stopping times t_1 < t_2 < … as successive visits to A separated by ≥ K steps. On {t_j < ∞}, P(death by t_j + K | F_{t_j}) ≥ δ. Hence P(t_{j+1} < ∞ and no death yet) ≤ (1−δ)·P(t_j < ∞ and no death yet) by optional conditioning, so P(infinitely many separated A-visits and survival) ≤ lim (1−δ)^j = 0; visits to A infinitely often implies infinitely many K-separated visits. ∎  CAUTION (as demanded): this does NOT yield a.s. death from A, because adversary nodes in A are only guaranteed ONE A-successor — the uniform draw can exit A into W with positive probability, and by Direction 1 a competent player then survives surely. So "a.s. death from the adversary's region" is FALSE in general; the equivalence needs, and we prove, exactly "death probability ≥ δ > 0 from A under every strategy". The prompt's suggested one-liner is repaired by D3's dichotomy.

================ (e) — honest assessment (no membership/hardness theorem claimed) ================
Everything here is COMPLETE as a set of conditional/expository claims; the classification itself is open.
1. What PSPACE membership would require. Since NPSPACE = PSPACE (Savitch), it suffices to exhibit, for every yes-instance, a certificate of size poly(|input|) checkable in PSPACE. The canonical membership certificate is an inductive invariant: a set S with s₀ ∈ S ⊆ Safe and S ⊆ CPre(S) (equivalently: a post-fixed point of F, which by Lemma C2 suffices — any such S is ⊆ W). W itself always works but has no a priori small description. If S is presented as a Boolean circuit C of size poly(nm) over the O(nm)-bit state encoding, then verifying "C(s₀)=1 ∧ ∀s [C(s) ⇒ s ≠ ⊥ ∧ ∃a ∀q C(succ(s,a,q))]" is a ∀∃-predicate over poly-length strings with the inner ∀q of constant width 7 and succ poly-time — checkable in Π₂^p, so ∃C-then-check ∈ Σ₃^p ⊆ PSPACE. Dually, non-membership is certified by a ranked adversary strategy (a rank function r: A → {0..K}; but K can be 2^{Θ(nm)}, so ranks need O(nm) bits — fine — while the DOMAIN description again needs succinctness). CONDITIONAL STATEMENT: if every yes-instance of P3 admits a poly(nm)-size circuit inductive invariant containing its s₀, then P3 ∈ Σ₃^p ⊆ PSPACE (and symmetrically for the no-side, though one side suffices for a promise-free algorithm only if BOTH sides are succinct or PSPACE=coPSPACE closure is exploited — PSPACE is closed under complement, so one side's succinct certificates + PSPACE verification already give P3 ∈ PSPACE for that side and its complement by exhaustive PSPACE search? NO — that reasoning is wrong and we do not use it: deciding requires certificates for whichever answer is true, i.e., succinct certificates for yes-instances AND for no-instances, or a genuinely different algorithm.) No such succinctness theorem is known. Empirically, this project's carrier searches (>10^6-state candidate closed sets, no small closed set found; memory notes on carrier walls) suggest that if succinct invariants exist they are not of the "small explicit set" form — they would have to be genuinely circuit-compressed.
2. Why the naive gfp does not give PSPACE. The fixpoint iteration maintains a subset of a 2^{O(nm)}-element arena: exponential space. Symbolically, iterating F on circuit-represented sets grows the circuit each round with no known poly-size bound on the νF iterates. The reformulation "survive forever ⟺ survive K rounds" (C1c) has K = 2^{Θ(nm)} in the worst case, so Theorem B's poly-space DFS becomes exponential-depth. Structurally: the natural decision procedure is an alternating computation in space O(nm), and APSPACE = EXPTIME exactly (Chandra–Kozen–Stockmeyer, JACM 1981) — poly-space alternation is CHARACTERIZED by EXPTIME, so this whole family of arguments cannot land in PSPACE.
3. Lower-bound side, honestly. Games on succinctly represented arenas (formula/circuit games, e.g., the G1–G6 family of Stockmeyer–Chandra, SIAM J. Comput. 1979, and the succinct-reachability-game folklore) are EXPTIME-complete in general, and P3 is precisely a safety game on a succinct exponential arena — so the "generic expectation" is EXPTIME-completeness. But no reduction from an EXPTIME-hard game INTO this specific Tetris ruleset (skyline hard drop, 7-bag, clears) is provided or known to me, and offline hardness results in the Tetris literature (NP-completeness of offline Tetris, Breukelaar–Demaine–Hohenberger–Hoogeboom–Kosters–Liben-Nowell, IJCGA 2004) use a different movement model (slides/rotations during descent) and do not transfer automatically. CONCLUSION: P3 ∈ EXPTIME unconditionally (Theorem C); P3 ∈ PSPACE is open; P3 EXPTIME-complete is open; if P3 were EXPTIME-complete then P3 ∉ PSPACE unless PSPACE = EXPTIME. No overclaim.

================ (f) THEOREM F — COMPLETE ================
Decidability: P4(n,m) asks whether the player survives forever from the initial configuration (empty board, fresh bag, adversary draws first). Formally P4(n,m) = true iff the V_A-position (∅board, ∅bag ≡ fresh) is in W, equivalently ∧_{q ∈ 7 types} [ (∅board, Full∖{q}, q) ∈ W ] — a conjunction of 7 P3 queries. Decidability is immediate from Theorem C. Encoding-sensitivity: (i) BINARY encoding: |input| = ℓ = Θ(log n + log m), and Theorem C's algorithm costs 2^{O(nm)} ≤ 2^{2^{c·ℓ}} for a constant c (since nm ≤ 2^{ℓ_n}·2^{ℓ_m} ≤ 2^{O(ℓ)}), so P4 ∈ 2-EXPTIME = DTIME(2^{2^{poly(ℓ)}}). The blow-up is exactly the phenomenon the prompt flags: P3's EXPTIME bound was relative to an input that already contains an nm-bit board; deleting the board from the input makes the same algorithm doubly exponential in the input length. (ii) UNARY encoding: ℓ = n + m, so 2^{O(nm)} = 2^{O(ℓ²)} = 2^{poly(ℓ)}, giving P4 ∈ EXPTIME. (iii) FIXED dimensions: for each constant (n,m) — e.g., canonical (10,20) — P4 is a fixed bit and the "problem" is O(1); complexity statements about P4 are meaningful only for the uniform family. No lower bound for P4 is claimed (its status inherits all of (e)'s openness; note also that P4 for fixed dims cannot be "hard" in any classical sense, so hardness must be asked for the family). Side remark (SKETCH, not needed for the theorem): survivability is monotone in m — a surviving strategy for (n,m) survives on (n,m′), m′ ≥ m, because the entire evolution (skyline drops, merges, full-width row clears) is identical when the strategy keeps height ≤ m ≤ m′; a full proof would formalize the board-embedding bisimulation and is omitted as it is not part of the claimed results.

## confidence_notes

Most delicate points, in order: (1) Theorem D Direction 2 — the rank induction must hold against randomized history-dependent players; this works ONLY because player nodes in the attractor have ALL successors of strictly smaller rank (a ∀-fact, robust to any action distribution), while the ≥1/7 factor is charged only at adversary nodes; conflating the two node types breaks the bound. (2) The explicitly flagged FALSITY of "a.s. death from the adversary's region": adversary nodes in A can have successors in W, so random draws can rescue the player; the equivalence only needs positive death probability, and Lemma D3 gives the correct dichotomy (death ∨ eventual absorption in W a.s.). This is where naive write-ups overclaim; I did not. (3) The 2^{nm} board count is sound only because loss is checked AFTER clears, so every non-lost state fits in n×m exactly as the ruleset specifies — with a loss-before-clear rule the state space and lemmas would need the m+4 rows throughout (same asymptotics, different constants). (4) In (b), the PSPACE bound leans on N being unary AND the board being an explicit part of the input (space O(N·nm) is polynomial only relative to that); both are per the problem statement. (5) In (c), EXPTIME (rather than 2-EXP) likewise depends on |input| ≥ nm via the explicit board bitmap — exactly the dependence that flips P4 to 2-EXPTIME under binary dims in (f); the two claims are consistent by construction. (6) The Σ₃^p bookkeeping in (e) is a conditional aside; if the inner quantifier accounting is off by a level it stays inside PSPACE, so the honest conclusion of (e) (open, no overclaim) is unaffected. (7) Engine-vs-prompt constant (117 vs 162 placements) verified against crates/tetris-game/src/tetris.rs; proofs are insensitive to it.
