## statements

MODEL (fixed once, used by all parts; verified against crates/tetris-game/src/tetris.rs `apply_piece_placement`/`clear_filled_rows`/`is_lost`).
Board space B_n = tuples b=(b_1,…,b_n), b_j a finite subset of {1,2,3,…} (rows unbounded; holes allowed). Height h(b)=max filled row (0 if empty); skyline H_j(b)=max(b_j ∪ {0}). A piece-rotation (p,ρ) has width w and, per footprint column i∈{0..w−1}, a contiguous vertical run with bottom offset t_i and length ℓ_i (all 19 tetromino rotation shapes have contiguous columns; engine stores exactly (t_i, run) as bit columns). Action a=(p,ρ,c), legal iff c+w ≤ n; legality and availability never depend on the board or on m. Merge(b,a): drop level D = max_i (H_{c+i}(b) − t_i); add to column c+i the rows D+t_i+1 … D+t_i+ℓ_i (rests on skyline; can never enter a cavity). Clear: R = {r : ∀j, r ∈ b_j}; Cl deletes R and shifts rows above down. step(b,a) = Cl(Merge(b,a)). Game G(n,m): loss set L_m = {b : h(b) > m}, checked ONLY after step (transient poke that clears back is not a loss). Bag: remaining bag β is a nonempty SUBSET of the 7 types (each bag = one of each), so ≤ 2^7−1 = 127 bag states; state s=(b,β,p); after the player's action commits, the adversary picks next piece q∈β (refill when empty). Strategies σ (player) and α (adversary) are arbitrary history functions. safe_{n,m} = {s : ∃σ surviving forever against all α in G(n,m)} (the gfp safe set = Atlas membership).

THEOREM A (Row monotonicity — strategy transfer up the ceiling). [COMPLETE] Let m ≤ m′. For every state s=(b,β,p) with h(b) ≤ m and every strategy σ: if σ survives forever from s in G(n,m), then the SAME σ survives forever from s in G(n,m′), and moreover for every adversary α the induced trajectory in G(n,m′) is identical (state-by-state) to the one in G(n,m). Consequently safe_{n,m} ⊆ safe_{n,m′} as subsets of the common state space, the same holds for N-step survival for every N, and any Atlas policy for (n,m) is verbatim an Atlas policy for (n,m′).

THEOREM B (Threshold structure). [COMPLETE] Define EmptySurv(n,m) ⟺ for every first draw p, (∅board, {7 types}∖{p}, p) ∈ safe_{n,m}. For each n, M(n) := {m : EmptySurv(n,m)} is upward closed; hence m*(n) := min M(n) ∈ ℕ ∪ {∞} exists and P4 = {(n,m) : m ≥ m*(n)}. For fixed n, P4 is a single integer comparison once m*(n) is known.

THEOREM C (Width transfer obstruction). Let e: B_n → B_{n+1} append an empty column.
C1 [COMPLETE] e commutes with step exactly on clear-free moves: if Merge(b,a) has no full row then step_{n+1}(e(b),a) = e(step_n(b,a)); and commutation FAILS whenever a clear fires — explicit witness (any n ≥ 4): b_1=∅, b_j={1,2,3,4} for j=2..n; a = vertical I in column 1. Then step_n(b,a) = ∅ (four clears) but step_{n+1}(e(b),a) = board of height 4 (no row full: column n+1 empty). So the clear operator, a global AND over all columns, is not preserved by column insertion (nor deletion, reading the witness backwards).
C2 [COMPLETE — quantitative failure of naive lifting] Let σ be ANY strategy for G(n,m) and σ̂ its lift to G(n+1,m) playing identical actions (all remain legal). From any start e(b0) with |b0| cells, against EVERY piece sequence, σ̂ loses within ⌊(nm − |b0|)/4⌋ + 1 placements. In particular no strategy that never touches the new column survives more than ⌊nm/4⌋+1 pieces at width n+1: width-n survival gives ZERO transferable guarantee at width n+1.
C3 [COMPLETE as stated] The reverse restriction (n+1 → n) is also unsound: actions with footprint meeting column n+1 are illegal at width n, and even footprint-legal plays diverge at the first clear (C1 witness). Whether survivability itself is monotone or non-monotone in n is left OPEN (both directions), as permitted by the task.

THEOREM D (Where the complexity lives).
D0 Upper bounds [COMPLETE, standard]: P1, P1′ ∈ NP (certificate = the placement sequence; each step simulable in O(nm); bag-legality of w checkable in linear time). P2 ∈ PSPACE (depth-N minimax DFS, N unary, branching ≤ max(#actions, 7), configuration size poly). P3 ∈ EXPTIME (safety game on ≤ 2^{nm}·127·7 states; gfp/attractor computation linear in game size). P4 is DECIDABLE, in time 2^{O(nm)} (instantiate P3 at the ≤7 empty-board start states).
D1 [COMPLETE] By Theorem B, P4 is the epigraph of the single function m*: ℕ → ℕ∪{∞}. Instances carry no board and no sequence; two instances with the same n differ only by a monotone comparison. The per-width information content of P4 is one integer.
D2 [COMPLETE, cites Mahaney / Karp–Lipton] Under unary encoding 1^n01^m, P4 has ≤ s+1 strings per length s, hence is SPARSE; by Mahaney's theorem, if P4 is NP-hard under Karp reductions then P = NP (a fortiori for PSPACE-hardness, which implies NP-hardness). Unconditionally, unary P4 ∈ P/poly with O(s log s) advice (the capped thresholds min(m*(n), s+1) for n ≤ s); so even NP ≤_T-hardness would give NP ⊆ P/poly and collapse PH to Σ2^p. Caveat: with BINARY-encoded dimensions sparseness fails (2^{Θ(s)} instances per length) and the Mahaney argument does not apply; the structural point (one integer per n) still stands.
D3 [COMPLETE — the honest converse] Nothing above makes P4 easy: deciding the single bit "m*(10) ≤ 20" is exactly the Atlas project, and the generic decision procedure runs in time ~2^{O(200)}. Worse, the FUNCTION n ↦ m*(n) is not obviously computable: certifying m*(n) = ∞ requires ruling out survival at every m, and no computable bound of the form "survivable at some m ⇒ survivable at m ≤ f(n)" is known. Conclusion: P4 is the wrong home for reduction-theoretic (NP/PSPACE-style) hardness; any such hardness for this ruleset MUST take the board (P2/P3: 2^{nm} instances) and/or the explicit sequence (P1/P1′) as input.

THEOREM E (Adversary information rate). [COMPLETE] At a step with k pieces remaining in the bag the adversary has ≤ k ≤ 7 options; over one bag exactly 7! = 5040 orders; over N pieces ≤ 5040^{⌈N/7⌉} behaviors. Rate = log2(7!)/7 = 12.2992…/7 ≈ 1.757 bits/piece. Player channel: log2(#actions) ≈ log2 162 ≈ 7.34 bits/step at n=10; board memory: up to nm bits. Frequency rigidity: any window of 7k consecutive pieces contains between k−1 and k+1 copies of EACH type (it contains ≥ k−1 complete bags and intersects ≤ k+1 bags). Bag-state count: 127 (nonempty subsets of 7); (bag, piece) pairs ≤ 7·127 = 889. Usable lower-bound facts: (i) adversary can inject ≤ 1.76 bits/step; (ii) piece STATISTICS are fixed to ±1 per type per bag window — only ORDER is adversarial; skewed-distribution killer sequences (e.g., S/Z floods à la Burgiel) are bag-illegal.

(f) GENERALIZED vs FIXED PIECE SETS.
F1 [COMPLETE] With pieces as part of the input, the offline CLEAR variant is strongly NP-hard even in this skyline model: reduction from 3-PARTITION using width k, height B, and vertical 1×a_i bar pieces in any fixed order — survive-and-end-empty ⟺ the a_i 3-partition into k columns of load exactly B.
F2 [SKETCH/OPEN] The survival-only generalized variant: the same reduction LEAKS (intermediate clears can rescue unbalanced loads — explicit 2-column leak exhibited); NP-hardness plausible but needs an anti-clear gadget; left open.
F3 [COMPLETE as an obstruction statement] With the fixed 7-tetromino alphabet plus bag legality, the "instance-in-the-pieces" channel of F1 is CLOSED: alphabet constant, counts rigid (Thm E), rate ≤ 1.76 bits/step. Hence any hardness proof for P1′/P2/P3 in this variant must encode the instance ENTIRELY in initial board geometry and simulate computation with an O(1)-information piece supply — this, plus the skyline movement model (no tucks/slides/spins, which the known Tetris NP-hardness gadgets of Demaine–Hohenberger–Liben-Nowell rely on, together with sequence-encoded numbers), is the central obstruction to importing SAT-style reductions.

## proofs

PRELIMINARY (engine ⇒ model, load-bearing): In tetris.rs, `apply_piece_placement` computes the drop from footprint-column heights only (top filled bit via leading_zeros = skyline), ORs the piece in, calls `clear_filled_rows` (mask = AND of all columns; cleared rows shifted down), and only afterwards evaluates `is_lost` (any bit above the ceiling). Neither Merge nor Cl mentions m; every action is always applicable (no spawn-block rule). This grounds the m-independence used below.

(a) THEOREM A. [COMPLETE]
Define the m-free labeled transition system T_n: states S = B_n × Bags × Pieces; a joint move at (b,β,p) is (player action a legal for p, adversary draw q ∈ β′ where β′ = β∖… with refill), successor (step(b,a), updated bag, q). By the preliminary, T_n is literally shared by G(n,m) and G(n,m′): the two games are (T_n, L_m) and (T_n, L_{m′}), and m ≤ m′ gives L_{m′} ⊆ L_m (h(b) > m′ ⇒ h(b) > m).
Fix σ surviving forever from s in G(n,m), and fix any adversary α. Let π = s_0 s_1 s_2 … be the unique infinite "loss-blind" play of (σ,α) in T_n from s_0 = s (well-defined: σ and α are history functions and T_n is deterministic given their choices).
Claim 1: the actual G(n,m)-play of (σ,α) equals π and never enters L_m. Induction on t: suppose the G(n,m)-play equals s_0…s_t and no loss has occurred. Then σ and α, applied to the identical history, produce the same joint move in both objects, so the next G(n,m)-state is s_{t+1}. If h(board(s_{t+1})) > m, the G(n,m)-play of (σ,α) is lost at step t+1, contradicting survival of σ. Hence s_{t+1} ∉ L_m and the induction continues. So every s_t on π satisfies h(board(s_t)) ≤ m.
Claim 2: the G(n,m′)-play of (σ,α) equals π and never enters L_{m′}. Same induction: histories coincide, moves coincide, and h(board(s_{t+1})) ≤ m ≤ m′ means the loss check in G(n,m′) never fires.
Since α was arbitrary, σ survives forever from s in G(n,m′), with identical trajectories. Hence safe_{n,m} ⊆ safe_{n,m′}. The same two-claim induction truncated at N steps gives the N-horizon statement. The initial condition h(b) ≤ m is automatic for any state from which σ survives even one step check, and holds for the empty board. Note the strategy is transferred VERBATIM (no re-indexing: the state spaces are the same set), and every trajectory-level invariant (holes, surface, clear rate, bag phase) transfers unchanged. ∎
Remark (direction): the converse fails in general — safe_{n,m′} states of height ≤ m need not be in safe_{n,m}; headroom is a real resource. (No claim needed; recorded to prevent misuse.)

(b) THEOREM B. [COMPLETE]
For each first piece p, {m : (∅, full∖{p}, p) ∈ safe_{n,m}} is upward closed by Theorem A (empty board has h = 0 ≤ m). EmptySurv(n,·) is the intersection of the ≤ 7 upward-closed sets, hence upward closed. An upward-closed subset of ℕ is either empty (m*(n) = ∞) or has a least element m*(n) with M(n) = {m ≥ m*(n)}. Therefore P4 = {(n,m) : m ≥ m*(n)}. ∎

(c) THEOREM C. [COMPLETE]
C1. Merge is column-local and skyline-driven: if a has footprint ⊆ {1..n}, then Merge_{n+1}(e(b),a) = e(Merge_n(b,a)) — the appended column is empty, is outside the footprint, and does not enter the drop-level max. Cl differs: a row is full in width n+1 only if column n+1 is filled there. If Merge_n(b,a) has no full row, then Merge_{n+1}(e(b),a) = e(Merge_n(b,a)) also has none (a full width-(n+1) row would restrict to a full width-n row), and Cl is the identity on both sides: commutation. Witness of failure: n ≥ 4, b = (∅, {1,2,3,4}, …, {1,2,3,4}), a = I vertical at column 1. Skylines: H_1 = 0, so D = 0 and the bar fills rows 1–4 of column 1; now rows 1–4 are full at width n, Cl gives the empty board. At width n+1: column n+1 empty at every row ⇒ R = ∅ ⇒ resulting board has height 4 ≠ e(∅). ∎
C2. Let σ̂ play σ's actions in G(n+1,m) from e(b0). Every footprint ⊆ {1..n} (legality at width n), so by induction column n+1 remains empty forever, so no row is EVER full, so Cl is always the identity along the entire play (any piece sequence, since σ's action set is unrestricted). Mass ledger: each placement adds exactly 4 cells and none are removed, so after t placements the board holds |b0| + 4t cells, all in columns 1..n. If the play is still alive after step t, the post-step board has h ≤ m (the loss check just passed and no clears occurred to excuse a poke), so all cells lie in the n×m box: |b0| + 4t ≤ nm, i.e., t ≤ (nm − |b0|)/4. Hence loss occurs at step ⌊(nm − |b0|)/4⌋ + 1 at the latest. ∎
C3. Immediate from C1 plus footprint-legality: a width-(n+1) action with c + w = n+2 does not exist at width n; and for footprint-legal actions the first clear along the play breaks the bisimulation by the C1 witness (read as: deleting the empty column CREATES clears). This proves no per-column-local simulation exists in either direction; it does NOT decide monotonicity of survivability in n, which we flag OPEN. ∎

(d) THEOREM D. 
D0 [COMPLETE, standard]: P1/P1′ ∈ NP: guess the placement sequence (length |w|, each action O(log) bits), simulate in O(|w|·nm), accept iff never lost (resp. also final board empty for the clear variant); bag-legality of w is a linear scan. P2 ∈ PSPACE: the value of the depth-N alternating game (player ≤ #actions ≤ O(n) branching, adversary ≤ 7) is computable by DFS storing one configuration (O(nm + log) bits) per level, N levels, N given in unary. P3 ∈ EXPTIME: the game graph has ≤ 2^{nm}·127·7 states (reachable boards fit in the n×m box between checks) and out-degree ≤ #actions·7; forever-survival in a safety game = complement of the adversary's attractor to L, computable in time linear in the graph. P4: build the P3 instance for (n,m), query the ≤ 7 start states; total 2^{O(nm)}. ∎
D1 [COMPLETE]: restatement of Theorem B; the language is {(n,m) : m ≥ m*(n)}, i.e., determined by the single sequence (m*(n))_n. ∎
D2 [COMPLETE modulo cited classics]: Sparseness: strings of length s in the unary encoding 1^n01^m are determined by the split point, ≤ s+1 of them, so |P4^{≤s}| ≤ poly(s). Mahaney's theorem (1982): a sparse ≤^p_m-hard set for NP exists iff P = NP. PSPACE-hardness ⇒ NP-hardness (SAT ∈ PSPACE), so the same conclusion. P/poly: advice at length s = the list (min(m*(n), s+1))_{n ≤ s}, O(s log s) bits; the decider parses (n,m), looks up, compares — correct because m ≤ s, so capping at s+1 preserves the comparison. If P4 were NP-hard under Turing reductions, NP ⊆ P^{P4} ⊆ P/poly, collapsing PH to Σ2^p (Karp–Lipton). ∎
D3 [COMPLETE as an argument, no theorem claimed]: Decidability per instance (D0) does not yield computability of n ↦ m*(n): computing m*(n) exactly requires either finding the least m with EmptySurv (semi-decidable by iterating D0) or certifying M(n) = ∅, which is a ∀m statement with no known reduction to a finite check — there is no proven bound f with "EmptySurv(n,m) for some m ⇒ EmptySurv(n, f(n))". (Theorem A gives upward closure, not an a priori ceiling on the threshold.) Hence the honest summary: P4 has trivial reduction-theoretic structure (D1/D2) yet each bit may be astronomically expensive (m*(10) ≤ 20 is the Atlas project, generic cost 2^{O(200)}); "hardness" of P4 is proof-search hardness, not instance-encoding hardness; instance-encoding hardness must live in P1/P1′/P2/P3 where inputs contain 2^{nm} boards or unbounded sequences. ∎

(e) THEOREM E. [COMPLETE]
Bag invariant: each bag contains each type exactly once, so the remaining multiset is a subset: ≤ 127 nonempty bag states; per draw the adversary chooses among |β| ≤ 7 pieces; a full bag realizes exactly 7! = 5040 orders; over N pieces the number of adversary behaviors against a fixed player is ≤ ∏(bag branchings) ≤ 5040^{⌈N/7⌉} = 2^{≈1.757N} (per-bag branching product 7·6·5·4·3·2·1). log2 5040 = 12.2992…; per-piece rate = 12.2992/7 ≈ 1.757 bits. Window rigidity: a window of 7k consecutive pieces starts inside some bag; it contains at least k−1 complete bags (7k consecutive positions cover ≥ k−1 full 7-blocks of the bag partition) and intersects at most k+1 bags; each type appears once per intersected bag, giving counts in [k−1, k+1]. Player-side and memory-side comparisons (log2 162 ≈ 7.34 bits/action at n=10; nm board bits) are direct counts. ∎

(f) F1 [COMPLETE] Reduction from 3-PARTITION (strongly NP-complete; integers a_1..a_{3k}, Σ a_i = kB, B/4 < a_i < B/2): board width k, height m = B, initial board empty, piece sequence = vertical 1×a_i bars in the given order, target = survive AND end with the empty board. Key structural fact: with single-column bars, every column is a solid prefix at all times (skyline landing on a solid prefix stays a solid prefix), so row r is full iff every column height ≥ r, and each clear subtracts the same number of rows from every column. Ledger: let L_j = total bar length routed to column j and C = total rows cleared during the play; final height of column j is exactly L_j − C (each cleared row was present in every column). Final board empty ⟺ L_j = C for all j ⟺ all L_j equal ⟺ L_j = B for all j (since Σ L_j = kB) — independent of when clears happened. Given a 3-partition, route each triple to its column: any column's height never exceeds its total load B ≥ (height at any time) so h ≤ m always, survival holds, and at the moment all columns reach B (at latest after the final bar) all B rows clear, ending empty. Conversely a surviving, board-clearing play yields L_j = B ∀j; B/4 < a_i < B/2 forces exactly 3 bars per column: a 3-partition. Instance is polynomial (unary numbers, strong NP-hardness). ∎
F2 [SKETCH] Survival-only leak: width 2, bars L_1 = B+d, L_2 = B−d with small pieces — interleaving lets both columns rise together, clearing d rows early, after which the overloaded column fits: survival without a balanced partition. So the survival-only generalized-piece problem needs an additional gadget (e.g., a pre-filled hole column that provably never clears, or scaled numbers making clears unaffordable); we exhibit the leak and leave hardness open.
F3 [COMPLETE as an obstruction argument] In P1′/P2/P3 the piece alphabet is the fixed 7 tetrominoes and (E) pins per-window counts to ±1 and order-information to ≤1.76 bits/step, so the F1 channel (numbers encoded as piece sizes/multiplicities) is unavailable; the only unbounded input object is the board. Any SAT/3-PARTITION-style reduction must therefore (i) encode the instance in initial board geometry, and (ii) make the fixed, near-uniform piece supply interact with that geometry to simulate choice/verification — under skyline-only movement, where the classical Tetris hardness gadgets (tuck/slide locks of Demaine–Hohenberger–Liben-Nowell; sequence-encoded numbers) are all unusable. This is the precise sense in which "hardness must come from board geometry alone." ∎

## gaps

1. Width monotonicity of survivability itself (both directions) is OPEN — (c) only proves the naive transfers are unsound, as the task permitted. Known killer-sequence results (Burgiel-style S/Z floods) are bag-illegal here (by Thm E's frequency rigidity), so they do not settle it.
2. Computability of the threshold function n ↦ m*(n) is OPEN: membership P4 is decidable per instance, but certifying m*(n) = ∞ has no known finite reduction; no bound "survivable at some m ⇒ survivable by height f(n)" is known. (For fixed (n,m) everything is a finite safety game.)
3. No completeness/hardness claims are made for P1/P1′/P2/P3 in THIS movement model with the fixed 7-piece alphabet — that is exactly the open frontier F3 identifies. Upper bounds (NP / NP / PSPACE / EXPTIME) are proven; matching lower bounds are open. In particular the literature's Tetris NP-completeness does NOT transfer (different movement model, sequence-encoded instances).
4. F2 (survival-only, generalized pieces) NP-hardness is left open; only the clear-the-board variant F1 is complete.
5. D2's rigorous version assumes UNARY dimension encoding (natural here, matching P2's unary horizon); for binary encoding the sparseness argument fails and only the informal "one integer per n" structure remains.
6. Mahaney's theorem and Karp–Lipton are cited, not reproved.
7. Assumption made explicit: strategies may be arbitrary history functions (the transfer in (a) works verbatim for memoryless ones too); the adversary is the standard adaptive-bag abstraction from the prompt; bag refill semantics (refill-then-draw vs draw-then-refill) do not affect any statement since both games in (a) share whichever convention the engine uses.

## confidence_notes

Delicate points, in decreasing order of load: (1) Theorem A hinges on the verified engine facts — landing computed from skylines only, clears before the loss check, actions always available, ceiling absent from dynamics; I re-verified these in tetris.rs (apply_piece_placement / clear_filled_rows / is_lost ordering) before writing the proof. One engine-vs-model nuance: the engine's u32 columns cap transient pokes at 32 rows; for m=20 a poke reaches ≤ 24 < 32, so engine and unbounded-column model agree; for generalized m the mathematical model is the reference object. (2) The two-claim induction in (a) must run over HISTORIES (not states) because strategies are history functions; as written it does. (3) C2's mass argument needs "alive ⇒ all cells in the n×m box," which holds because in the lifted play clears never occur, so a post-step height > m is an immediate loss. (4) D2: Mahaney requires many-one poly reductions; for Turing reductions only the P/poly + Karp–Lipton collapse is claimed — kept separate deliberately. (5) F1's soundness rests on the solid-prefix invariant for single-column bars and the exact ledger final_height_j = L_j − C; both are immediate in the skyline model but would fail with slides — this reduction is specific to our movement model, which is a feature (it shows the generalized-alphabet problem is hard even here). (6) Thm E's window bound [k−1, k+1] is tight in general and stated conservatively; the exact per-step branching depends on bag phase (product over a bag is exactly 7!).
