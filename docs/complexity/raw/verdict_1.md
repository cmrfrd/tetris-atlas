The theorem suite is substantially sound. All three targeted attacks were pressed to ground truth against crates/tetris-game/src/tetris.rs. (a) Theorem A's core mechanism is CORRECT: trajectory states are post-clear states, both games check loss only there, L_{m'} ⊆ L_m, and the transient poke-then-clear case never appears as a checked state; the m-board strategy is never queried on an unseen history because the loss-blind plays coincide state-by-state. One false justification sentence and one semantics ambiguity found (repairable, theorem survives under either reading). (b) Theorem C is correct in all its formal claims (C1 witness verified; C2 mass ledger verified: no clears ever fire with the appended column empty, |b0|+4t ≤ nm bound exact); one sentence in C3 overclaims. (c) Theorem D does NOT commit the feared overclaim: P4's decidability is derived per-instance from the finite safety game (D0), not from threshold structure; computability of n ↦ m*(n) is explicitly disclaimed (D3 + gap 2); binary-encoding failure of sparseness is explicitly flagged (gap 5); Mahaney, the O(s log s) capped-advice construction, and the Karp–Lipton Turing-hardness corollary all check out. The one substantive error in the suite is F3's blanket "instance must live entirely in board geometry" claim, which is false for P1' (bag-legal order is an unbounded ~1.757 bit/piece input channel by the document's own Theorem E) though correct for P2/P3. ## errors_found

E1 (Theorem A proof, minor but real): "The initial condition h(b) ≤ m is automatic for any state from which σ survives even one step check" is FALSE under the stated model semantics (loss checked ONLY after step): a state with h(b)=m+2 whose every opening move clears back below m passes every step check, so safe_{n,m} can contain h>m states; surviving the first check constrains the POST-step state, not the initial one. As written, the corollary safe_{n,m} ⊆ safe_{n,m'} is claimed for all of safe_{n,m} while the proof covers only h ≤ m states, with the gap bridged by this false remark. E2 (model/engine mismatch behind E1): the engine additionally checks is_lost BEFORE each placement (tetris.rs line 2184 early-exit), so "loss checked ONLY after step" is not exactly the engine's semantics; under engine semantics the remark in E1 becomes true but the model statement is then wrong about the engine. The two semantics differ precisely on h(b)>m start states. E3 (grounding overclaim): the preliminary claims the engine verifies the m-free unbounded-rows model, but the engine uses u32 columns with pieces spawning at bit rows 28-31 and computes the drop via col_height.abs_diff(TRAILING[I]) (line 2211) — abs_diff silently inverts for footprint heights > ~28 and rows above 32 vanish; the engine grounds the model only for m ≤ 28 (canonical 10x20 fine). E4 (C3, one-sentence overclaim): "This proves no per-column-local simulation exists in either direction" — only three specific maps were refuted (append-column embedding, identity-action strategy lift, restriction); "per-column-local simulation" is undefined and no universal impossibility was proven. The honest OPEN flag on width monotonicity is correct. E5 (F3, the main substantive error): "the only unbounded input object is the board" and "any hardness proof must encode the instance ENTIRELY in initial board geometry" are FALSE for P1' (OFFLINE-HD-BAG): the explicit bag-legal sequence w is unbounded input whose ORDER carries Theta(|w|) bits (log2(7!) ≈ 12.3 bits per bag ≈ 1.757 bits/piece — the document's own Theorem E rate); bag-legality rigidifies COUNTS (closing the F1 numbers-as-multiplicities channel) but only thins, does not close, the sequence-order channel. This also contradicts D3's own "inputs contain 2^{nm} boards OR UNBOUNDED SEQUENCES". The claim is correct for P2/P3 (adaptive adversary, no sequence in the input). E6 (F1, minor under-specification): the reduction needs each input bar piece to come with a single (vertical) rotation state; if the generalized-piece model forced rotation-closure, horizontal 1xa bars could perturb the gadget. The model's piece-rotation-list format permits this, but it is never stated. NON-ERRORS (attacks that fail): the transient-overflow attack on Theorem A fails — the induction only ever inspects post-clear states and Merge/Cl are verified m-free, so a height-m state poking to m+2 and clearing to m-1 is handled identically and invisibly in both games, and strategy domain is never exceeded since histories coincide; the D2/D0 decidability attack fails — decidability of P4 comes from the finite safety game per instance (alive boards fit the nxm box), NOT from threshold structure, and computability of the threshold function m*(n) (where genuine undecidability could hide, in certifying m*(n)=infinity) is explicitly left open; sparseness, the capped-advice P/poly construction (m ≤ s < s+1 so capping preserves the comparison), Mahaney for Karp reductions, PSPACE-hard implies NP-hard, and Karp-Lipton via P^{P4} ⊆ P/poly are all correctly applied, with the unary-encoding dependence explicitly confined (gap 5). Verified correct by direct check: C1 witness, C2 ledger, Theorem B, Theorem E arithmetic and window rigidity [k-1,k+1], F1 forward/converse including transient heights, D0 upper bounds, 162 actions (CLAUDE.md's 117 is outdated, not the document).
